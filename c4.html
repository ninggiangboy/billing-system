Generic Billing System

Billing prices usage and runs the financial workflow for many kinds of resource-rental services. Client Systems keep full control of Resource, Order and Execution; Billing only publishes status through APIs, events and webhooks. Growing to ten times the target load takes added capacity, with no change to the API or event contract.
